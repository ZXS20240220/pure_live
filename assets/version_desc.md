### 📝 本次更新

**version: 1.0.7 (build 314)**

#### 🎨 壁纸与外观

- 实现完整壁纸模块：支持纯色 / 图片 / 视频壁纸 / 在线图库，可在设置中切换与预览 (参照上游)
- 新增"已保存壁纸"管理页：查看并再次应用历史壁纸
- 壁纸设置纳入备份与恢复范围
- 优化窗口背景模糊效果，避免 Windows 上命中测试异常导致点击穿透
- 统一全站下拉刷新为 ClassicHeader 样式
- 直播平台新增 logo 图标，优化平台选择与搜索体验 (参照上游)
- 观众信息（热度）数字过长时，鼠标悬停显示完整数值

#### 💬 弹幕

- 新增海量弹幕模式与弹幕字间距设置 (参照上游)
- 弹幕字体大小、字间距可调；样式调整后已上屏的弹幕会实时跟随变化
- 小窗弹幕继承字间距设置
- B 站弹幕支持显示表情图片 (参照上游)
- Twitch 弹幕支持通知与撤回 (参照上游)
- 添加快捷键 Ctrl+D 切换弹幕显示，并在播放页控件栏中提供快捷键帮助说明
- 统一悬浮窗弹幕按钮图标样式

#### 🎬 播放器与窗口

- Windows 启用 SMTC 系统媒体控制，支持媒体键与系统音量条联动 (参照上游)
- 小窗与 Windows 画中画跟随视频实际比例自动调整窗口
- Windows 画中画观看会计入观看时长 (其他小窗仍不计入)
- 切换直播间时保留旧悬浮窗兜底，避免后台音频残留
- 从小窗恢复到大窗时同步更新观看历史与收藏信息
- 移动布局添加小窗宿主，修复切换直播间时小窗不可见
- 调整紧凑布局宽度阈值，优化底部操作栏显示
- 修复直播间顶栏区域单击延迟
- 修复窄屏下面板宽度 clamp 抛出错误导致白屏
- 新增直播画质与缓冲（buffering）设置
- 录制 EOF 重试有上限，合并分段容忍空分段
- 起播（mpv open）前预置保存音量，消除开屏 100% 炸音

#### 📺 清晰度与录制

- 清晰度智能选择策略：添加多显示器选择功能以优化匹配
- 录制画质移除"智能分辨率"选项，确保选择更一致

#### 🏠 房间与分区

- 优化分区页内容：现在分区显示完整内容，不会缺少直播间，同时过滤录播房间
- 直播间顶栏信息根据窗口宽度自动隐藏，避免小窗口拥挤
- 各平台直播开始时间支持，优化直播信息展示
- 列表布局下支持按住 Ctrl 点击房间卡片直接悬浮窗播放
- 错误回退逻辑返回"未知状态"副本而非误判为离线

#### 🔍 搜索与网页

- 优化网页搜索的房间链接检测逻辑，增强对特定域名的支持
- 修复 webview 网页跳转直播间问题
- 虎牙搜索与分组树请求补 User-Agent，修复 403 (参照上游)
- 斗鱼账号登出清除整段会话（含 passport 字段）

#### 📦 备份与远程同步

#### ✅ 测试与稳定性

- 全面修复 test 测试，并修复潜在 bug
